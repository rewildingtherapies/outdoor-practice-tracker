# Practice Setup Milestone Tracker

An interactive milestone tracker for therapists and practitioners setting up outdoor practice.

Part of **The Outdoor Practice** by Rewilding Therapies.

## What it does

Takes practitioners through seven phases of setting up outdoor therapeutic work, from foundations to launch. Progress saves automatically in the browser. Once the first phase is complete, a Brevo signup form appears to join the practitioner mailing list.

## Live site

Deployed via GitHub Pages. See the repo settings for the live URL.

## Files

- `index.html` — the whole tracker, self-contained. No build step.

## Making changes

Edit `index.html` directly on GitHub or locally. Commit, push, and GitHub Pages redeploys in about a minute.
